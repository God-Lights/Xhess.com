Albatross

브라우저용 체스 엔진 · 파일 하나 · 설치 없음 · v__VERSION__

다운로드

WebAssembly 가 들어 있는 자바스크립트 파일 하나(__SIZE__ KB)입니다. 웹 워커로 실행하면 UCI 로 대화합니다.

albatross.js (최신) albatross-__VERSION__.js (버전 고정) albatross-loader.js (선택)

SHA-256 (albatross.js): __SHA256__

1. 내 사이트에 올려서 쓰기

내려받은 albatross.js 를 내 서버에 올리고 같은 사이트에서 웹 워커로 엽니다.

const engine = new Worker('albatross.js');
engine.onmessage = (e) => console.log(e.data);   // "uciok", "info depth 8 ...", "bestmove e2e4"
engine.postMessage('uci');
engine.postMessage('position startpos moves e2e4 e7e5');
engine.postMessage('go movetime 1000');

2. 다운로드 없이, 어느 사이트에서든

브라우저는 다른 사이트의 파일로 new Worker(url) 를 만들지 못합니다. 로더가 엔진을 가져와 blob: 워커로 시작해 줍니다. 이 사이트는 어느 출처에서든 가져갈 수 있게(CORS) 열려 있습니다.

<script src="https://…/engine/albatross-loader.js"></script>
<script>
  createAlbatross().then(function (engine) {          // 웹 워커(UCI)
    engine.onmessage = function (e) { console.log(e.data); };
    engine.postMessage('uci');
    engine.postMessage('position startpos');
    engine.postMessage('go depth 12');
  });
</script>

엄격한 Content-Security-Policy 가 있는 페이지는 worker-src blob: 과 이 사이트로의 connect-src 를 허용해야 합니다.

알아둘 점

  • 단일 스레드입니다. 탐색은 전용 워커에서 돌기 때문에 페이지는 멈추지 않습니다.
  • stop 은 엔진 워커를 다시 시작합니다(WebAssembly 탐색은 안쪽에서 끊을 수 없기 때문). 지금까지 끝낸 가장 깊은 수를 bestmove 로 돌려주고, 위치와 옵션은 복원되지만 해시 테이블은 비워집니다.
  • 필요한 것: Web Worker, WebAssembly, 워커 안의 워커(Chrome·Edge·Firefox 최신, Safari 15 이상).
  • 강도: 같은 계열 이전 버전(0.3)에 +129 Elo(200판, 수당 50 ms, 95% 구간 +85~+177). 다른 엔진 대비 절대 강도는 측정하지 않았습니다.
  • 속도는 같은 코드의 네이티브 빌드보다 느립니다(이 개발 환경에서 약 1.5 M nps 수준, 기기에 따라 다릅니다).
