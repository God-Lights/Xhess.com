# 전략 마킹 (Strategy Marking)

보드 위 화살표로 **엔진의 추천**과 **내 계획**을 보여 주는 기능. 앱의 "전략 마킹" 체크박스로 켜고 끈다(기본 켜짐).

## 무엇이 보이나
| 표시 | 의미 |
|---|---|
| 초록 굵은 화살표 + `1` | 엔진 1순위 수 |
| 빨간 화살표 | 1순위 수에 대한 엔진의 예상 응수 |
| 연한 초록 화살표 | 그 다음 내 수(1순위 라인의 3번째 수) |
| 파랑 `2`, 노랑 `3` | 대안 수 (첫 수만) |
| 패널 목록 | `1. e4 +0.26 e5 Nf3 Nf6 Nc3` — 번호는 화살표 번호와 같고, 평가값은 **내 관점**(+가 유리) |

### 내 계획 (오른쪽 클릭 드래그)
보드에서 **오른쪽 클릭 드래그**로 내가 둘 수를 화살표로 그리면, 엔진이 **그 수만** 평가한다(UCI `searchmoves`).

- 보고서: 내 수의 평가, 엔진 최선과의 차이(손해), 판정(최선에 가까운 수 / 좋은 수 / 부정확 / 실수 / 큰 실수), 엔진이 예상하는 상대 응수.
- 화살표를 **두 개** 그리면 두 번째를 "내가 예상하는 상대 응수"로 보고, 엔진 예상과 **일치/불일치**를 알려 준다.
- 합법적이지 않은 화살표는 무시한다. 수를 두거나 새 게임을 시작하면 표시가 지워진다.

판정 기준(손해, 센티폰): ≤15 최선에 가까움, ≤60 좋음, ≤150 부정확, ≤300 실수, 그 이상 큰 실수.

## 구조
```
엔진(UCI: MultiPV, searchmoves)  ──  app/src/engine/uci.ts   analyze() / parseInfo()
                                      app/src/analysis.ts     Analyzer: 분석 수명주기(취소·교체·결과 폐기)
                                      app/src/strategy.ts     순수 로직: 점수 변환, 도형 생성, 계획 해석, 판정
                                      app/src/main.ts         chessground autoShapes / drawable.onChange 연결
```
- 표준 UCI 만 쓰므로 **Stockfish(WASM·네이티브)와 Albatross 둘 다** 같은 코드로 동작한다.
- 분석은 **내 차례이고 엔진이 쉬는 동안에만** 돌고, 수를 두는 순간 먼저 멈춘 뒤에 엔진이 둔다(`Analyzer.cancel()` 이 멈춤 완료까지 기다림).
- 분석 중에는 대국용 약화 설정(Skill Level)을 풀고, 끝나면 슬라이더 값으로 되돌린다. 분석이 끝나면 `MultiPV` 도 1 로 복원한다.
- `go ... searchmoves` 는 **항상 마지막**에 둔다. Stockfish 는 그 뒤 토큰을 모두 수 목록으로 읽어 `movetime` 이 무시되기 때문(실제로 겪은 문제).

## 검증
- 단위 테스트(앱): 점수 정렬·표시, 라인 수집, 합법 수열, 도형 생성, 계획 해석, 판정, 보고서, 가짜 UCI 엔진으로 `Analyzer` 의 취소·교체·재사용·옵션 복원·명령 순서.
- 통합 테스트(실제 Albatross): `ALBATROSS_BIN=engine/build/albatross npm test` — MultiPV 3, `searchmoves`, 분석 중 `stop` 후 재사용.
- 브라우저 E2E(Playwright, 실제 Stockfish WASM): 추천 화살표 5개와 후보 목록 3줄 표시, 오른쪽 클릭 드래그로 그린 계획의 평가 보고서, 수를 둔 뒤 엔진 응답과 다음 차례의 새 분석, 끄면 화살표·목록 제거.
- 엔진: `MultiPV`/`searchmoves` 테스트 5개 포함 65개 통과(GCC·clang·ASan+UBSan·TSan). `MultiPV=1` 은 기존과 노드 수가 동일(`bench 6` = 285,998).

## 알려진 한계
- **모바일(터치)에서는 계획 화살표를 그릴 수 없다.** chessground 가 오른쪽 클릭으로만 화살표를 그린다. 터치용 "계획 그리기" 모드는 아직이다. 엔진 추천 화살표와 목록은 모바일에서도 보인다.
- 평가값은 분석 시간(추천 3초, 계획 1.5초)과 엔진 상태에 따라 조금씩 다르다. 계획 평가 중 진행 중이던 추천 분석을 끼워 쓰면 목록과 보고서의 최선 평가값이 약간 어긋날 수 있다.
- "전략"은 아직 **수와 예상 수순**(화살표) 수준이다. 약한 칸·열린 파일·통과폰·킹 안전 같은 **테마 표시**는 평가 함수에 항목별 점수가 생기는 0.4(Position Sense)와 함께 만든다.
- 계획은 첫 수만 엔진이 탐색한다. 두 번째 이후 화살표는 예상 응수 비교에만 쓴다(긴 계획의 단계별 평가는 이후).
